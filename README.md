# Charvi Portfolio

My full-stack personal portfolio built with React, Tailwind CSS,
Node.js, Express, and MongoDB.

🌐 **Live website:** [Visit my portfolio](https://charvi-portfolio-coral.vercel.app/)

## Features
- Skills and education
- GitHub projects
- Downloadable resume
- Portfolio chatbot
- Contact and social links

## Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
